## 주제
서울시 생활 정보 기반 대중교통 수요 분석   
(미션: 버스 노선 추가가 필요한 서울 시 내 자치구 선정)

## 중점사항
1. 분석/모델링을 위한 데이터 구조 이해
2. 정보의 종류(숫자,범주)에 따라 데이터의 분포 확인
3. 경험이나 비즈니스 관점으로 가설 수립 및 검증 (Y에 영향을 주는 요인 X 도출)
4. 변수 간 관계의 정도를 파악하고 시각화, 수치화 해보기

## 데이터
생활이동 정보 등의 Tabular 데이터 (csv 파일)

## 데이터 출처
서울 생활이동> 서울빅데이터 | 서울열린데이터광장 (seoul.go.kr)
